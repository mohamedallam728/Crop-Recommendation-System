# 🌾 Smart Crop Recommendation System

## 📌 Project Overview
An AI-driven system designed to recommend the most suitable crop for cultivation based on soil metrics (N, P, K, pH) and environmental conditions (Temperature, Humidity, Rainfall). 

Developed as part of the **NTI & ITIDA Summer Training Program (2026)**.

## 📂 Repository Structure
This repository contains the complete pipeline for the project:
1. **`Crop_Recommendation_Model_Training.ipynb`**: The Jupyter Notebook containing the Exploratory Data Analysis (EDA), Data Preprocessing, and the training/evaluation of 4 Machine Learning models (Decision Tree, SVM, Random Forest, XGBoost).
2. **`app.py`**: The Streamlit web application script for the interactive User Interface and deployment.
3. **`*.pkl files`**: The exported trained XGBoost model and Label Encoder.

## 🚀 Features & Explainable AI
* Interactive UI using Streamlit.
* Algorithm Accuracy Comparison.
* **Feature Importance:** Integrated visualization to explain the AI's decision-making process.

## 🛠️ Technologies Used
* **Data Science:** Python, Pandas, NumPy, Matplotlib, Seaborn
* **Machine Learning:** Scikit-Learn, XGBoost
* **Deployment:** Streamlit
